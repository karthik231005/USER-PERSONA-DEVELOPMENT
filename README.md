PersonaFlow


Turning User Research into Meaningful Personas

🎓 Internship Project | Intern ID: CITS7783 | Codtech IT Solutions Pvt. Ltd.

PersonaFlow is a centralized hub that helps UX researchers and product teams synthesize qualitative insights, visualize user journeys, and transform raw research data into actionable, empathetic personas for product design.

📱 About the Project

PersonaFlow is a mobile-first application UI designed to streamline the end-to-end UX research workflow — from raw interviews and surveys to fully synthesized personas, journey maps, and strategic design recommendations.

Core Navigation

The app is organized around a bottom navigation bar with five main sections:

Home – Overview and entry point to the app
Personas – Persona gallery and detail views
Maps – User journeys and empathy maps
Insights – Key findings dashboard
Study – Case studies and recommendations
✨ Key Features
🏠 Home

Landing screen introducing the app's purpose, with quick access to "Explore Personas" and "View Case Study," plus summary research-impact stats (interviews conducted, personas created, pain points identified, user needs uncovered).

🔬 Research Process

A vertical tracker visualizing the research methodology pipeline — Interviews, Surveys, Observation, Affinity Mapping, Pattern Identification, and Persona Creation — each with status indicators (Done / Active) and progress details.

👤 Persona Gallery & Detail
Gallery view: Searchable list of persona archetypes (e.g., Arun the Busy Student, Priya the Career Professional, Rahul the Tech Enthusiast, Meena the New Digital User) with quick tags, primary goals, and main pain points.
Detail view: Full persona profile including quote, age, occupation, location, goals, needs, pain points, behaviors, and motivation metrics.
🗺️ Journey Mapping

Stage-by-stage visualization of a persona's experience (e.g., Awareness → Consideration → Decision), tracking emotional state, actions taken, and pain points at each stage.

🧠 Empathy Map

Classic four-quadrant empathy map (Says / Thinks / Does / Feels) capturing a persona's mindset in their own words.

📊 Insights Dashboard

Aggregated findings from interviews and usability testing, including top user needs, common frustrations, design opportunities, behavior breakdowns, and prioritized user goals.

📄 Case Study

Detailed write-up of a research initiative — problem statement, methodology, persona development process, measurable outcomes (e.g., 40% time saved), and lessons learned.

💡 Strategic Recommendations

Actionable design recommendations derived from research, each tagged by category (UX/UI Design, Accessibility, Feature Request) and linked back to the specific persona pain point it addresses.

🎨 Design System
Theme: Dark mode UI with a purple/indigo accent palette
Style: Card-based layout with rounded corners and soft shadows
Typography: Bold headers with muted, secondary descriptive text
Components: Progress bars, status pills, tag chips, and icon-led section headers throughout
